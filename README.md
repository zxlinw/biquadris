# biquadris

Biquadris is a two-player Tetris-like game built in **C++** for CS246: Object-Oriented Software Development at the University of Waterloo.  It features a graphical interface using the XWindows library. Players take turns placing and rotating blocks, clearing rows, and trying to avoid overflowing their board. The first player to fill up their board loses the game. The game also features different difficulty levels, high score tracking, and special multiplayer effects that can be triggered during the game.

Features
- Two-player turn-based gameplay
- Movement (left, right, down), rotation, row clearing
- 5 different difficulty levels
- High score tracking
- GUI built with XWindows
